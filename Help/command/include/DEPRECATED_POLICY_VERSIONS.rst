.. versionchanged:: 4.0

  与CMake 3.5之前版本的兼容性已被移除。调用\ :command:`cmake_minimum_required(VERSION)`\
  或\ :command:`cmake_policy(VERSION)`\ 时，若未将策略版本至少指定为3.5（可通过\
  ``...<policy_max>``\ 可选指定），在CMake 4.0及更高版本中将会产生弃用错误。
