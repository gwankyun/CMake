.. _`CMakePresets.configurePresets.name`:

``name``
  一个必需字符串，表示该预设便于机器处理的名称。此标识符用于
  :option:`cmake --preset` 选项。在 ``CMakePresets.json`` 与
  ``CMakeUserPresets.json`` 于同一目录下的并集中，不得存在两个同名的配置预设。
  不过，配置预设可以与构建、测试、打包或工作流预设同名。

.. _`CMakePresets.configurePresets.hidden`:

``hidden``
  一个可选布尔值，指定是否隐藏该预设。如果预设被隐藏，它便不能用于
  :cmake-option:`--preset` 参数，不会显示在
  :manual:`CMake GUI <cmake-gui(1)>` 中，而且即使通过继承也不必具有有效的
  ``generator`` 或 ``binaryDir``。``hidden`` 预设旨在作为基础，供其他预设通过
  ``inherits`` 字段继承。

.. _`CMakePresets.configurePresets.inherits`:

``inherits``
  一个可选的字符串数组，表示要继承的预设的名称。此字段也可以
  是单个字符串，等价于只包含一个字符串的数组。

  默认情况下，该预设会继承 ``inherits`` 所列预设的全部字段，但 ``name``、``hidden``、
  ``inherits``、``description`` 和 ``displayName`` 除外；其余字段可以按需覆盖。
  如果多个 ``inherits`` 预设为同一字段提供了相互冲突的值，将优先采用 ``inherits``
  数组中靠前的预设。

  预设只能继承在同一个文件中、或在该文件（直接或间接）包含的文件中定义的预设。
  ``CMakePresets.json`` 中的预设不能继承 ``CMakeUserPresets.json`` 中的预设。
