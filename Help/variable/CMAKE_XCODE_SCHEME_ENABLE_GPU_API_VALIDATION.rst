CMAKE_XCODE_SCHEME_ENABLE_GPU_API_VALIDATION
--------------------------------------------

.. versionadded:: 3.25

在Options部分填充\ ``Metal: API Validation``\ 生成的Xcode方案。

This variable initializes the
:prop_tgt:`XCODE_SCHEME_ENABLE_GPU_API_VALIDATION` property on all targets.
