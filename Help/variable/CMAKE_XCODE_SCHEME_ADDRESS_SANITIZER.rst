CMAKE_XCODE_SCHEME_ADDRESS_SANITIZER
------------------------------------

.. versionadded:: 3.13

是否在生成的Xcode方案的Diagnostics部分启用\ ``Address Sanitizer`` 。

This variable initializes the
:prop_tgt:`XCODE_SCHEME_ADDRESS_SANITIZER`
property on all targets.
