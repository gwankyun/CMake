CMAKE_XCODE_SCHEME_WORKING_DIRECTORY
------------------------------------

.. versionadded:: 3.17

在生成的Xcode方案中指定\ *Run*\ 和\ *Profile*\ 操作的\ ``Working Directory``。

This variable initializes the
:prop_tgt:`XCODE_SCHEME_WORKING_DIRECTORY`
property on all targets.
