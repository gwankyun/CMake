CMAKE_XCODE_SCHEME_ENABLE_GPU_SHADER_VALIDATION
-----------------------------------------------

.. versionadded:: 3.25

在生成的Xcode方案的“选项”部分填充\ ``Metal: Shader Validation``。

This variable initializes the
:prop_tgt:`XCODE_SCHEME_ENABLE_GPU_SHADER_VALIDATION` property on all targets.
