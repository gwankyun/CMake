CMAKE_XCODE_SCHEME_DISABLE_MAIN_THREAD_CHECKER
----------------------------------------------

.. versionadded:: 3.13

是否在生成的Xcode方案的诊断部分禁用\ ``Main Thread Checker``。

This variable initializes the
:prop_tgt:`XCODE_SCHEME_DISABLE_MAIN_THREAD_CHECKER`
property on all targets.
